# Mensaje inicial para Antigravity IDE (copiar y pegar)

Ya tienes abierto el repositorio y seguimiento completo del proyecto **Sistema Web de Inventario Tecnológico con Códigos QR — I. E. Nuestra Señora del Perpetuo Socorro, Piura 2026**. Toma como reglas obligatorias `AGENTS.md` y las skills en `.agents/skills/`. No inicies otro proyecto ni reemplaces la aplicación móvil existente.

**Primera tarea: auditoría y plan ejecutable.** Inspecciona el estado actual del repositorio, su árbol, dependencias, migraciones, clases, componentes, configuraciones, contratos API, pruebas y estado de Git. Identifica qué está implementado, qué falta, qué debe refactorizarse y qué podría romperse; no borres código. Contrasta la implementación con RF01-RF07 y RNF01-RNF06 del proyecto y presenta un plan por fases con archivos concretos a modificar. No inventes qué contiene el repositorio.

**Arquitectura obligatoria:** React + Vite feature-first con componentes compartidos, hooks, servicios y CSS Modules por funcionalidad; temas claro, oscuro y combinado mediante tokens CSS semánticos; diseño sencillo, márgenes regulares, border-radius discretos, transiciones suaves, skeletons y estados vacío/error/carga. Backend PHP API REST como monolito modular Controller–Service–Repository con PSR-4, clases separadas y límites por dominio. MySQL con MER, cardinalidades, migraciones, FKs reales, UNIQUE y normalización. Desarrollo y pruebas en Docker Compose sin instalar PHP/Node/MySQL nativamente en el host. Producción preparada para un cPanel tradicional sin depender de Docker.

**Autenticación y seguridad:** cuentas propias del sistema, roles y permisos controlados en backend, contraseñas hasheadas con algoritmo resistente, cookie de sesión segura y mitigaciones OWASP. Recuperación por email: crear una cuenta SMTP remitente dedicada en cPanel; usar usuario y contraseña DE ESE BUZÓN solo como secretos del backend, nunca usuario o contraseña administrativos de cPanel. Generar código numérico seguro de 8 dígitos, vencimiento de 10 minutos como máximo, un solo uso, hasta 5 intentos, límites de solicitud por cuenta e IP, sin enumeración de usuarios, registro solo del evento sin código. Preparar prueba con Mailpit en local. Nunca devolver códigos ni secretos al frontend.

**Configuración central:** administrador cambia nombre y logo del sistema, datos institucionales y tema predeterminado. Los cambios deben verse en login, encabezados, plantillas de impresión, documentos exportados, imagen/QR y metadatos/nombrado de respaldos, respetando seguridad, control de acceso y configuración por usuario cuando sea aplicable. Tres temas: claro, oscuro, combinado (barra lateral oscura + contenido claro); editar módulos individualmente sin efecto dominó.

**Inventario y QR:** ubicación y estado actual de cada equipo, historial de movimientos cuando corresponda, consulta de ficha con permisos, generación/descarga de QR identificador opaco no predecible, ruta de resolución segura y conexión con aplicación móvil EXISTENTE. Inspecciona primero contratos de la app móvil y preserva compatibilidad. Incorporar registro, aprobación y revocación de dispositivos si hay vinculación persistente; cámara/QR no implica acceso a datos privados.

**Calidad, cPanel y entrega:** verifica PHP/extensiones y MySQL reales del hosting antes de decidir versiones locales. Entrega despliegue cPanel mediante React compilado, API PHP y scripts/migraciones sin publicar `.env`, `/src`, `vendor` interno sensible, logs ni respaldos. Prevé HTTPS, seguridad de cabeceras, controles de sesión y acceso, SMTP TLS, backups cifrados protegidos, restauración probada, rollback y pruebas OWASP. Cada funcionalidad debe tener criterios de aceptación y pruebas.

**Forma de trabajo:** primero muestra diagnóstico, MER propuesto y estructura de carpetas. Después implementa una vertical funcional a la vez, ejecutando comprobaciones dentro de Docker y reportando resultados reales. Si falta una credencial, URL, acceso al hosting o referencia de GitHub, marca ese punto pendiente y crea placeholders seguros; nunca inventes valores. Antes de operaciones destructivas o despliegue público, solicita aprobación explícita.
